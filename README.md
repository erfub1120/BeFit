# BeFit

A fitness tracking application built with .NET 8 and modern web technologies.

## Tech Stack

- **.NET 8** - Backend framework
- **ASP.NET Core** - Web API
- **Entity Framework Core** - Database ORM
- **SQL Server** - Database (or specify your database)

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- SQLite
